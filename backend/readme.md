YouTube Approval Layer — MERN (Production-Ready)

A clean, simple, and secure YouTube Approval Workflow app built with the MERN stack.
Editors upload videos, admins review and approve, and once approved — the video automatically uploads to YouTube using a secure refresh-token workflow.

This project focuses on:

🔐 Secure Auth (JWT + Protected Routes)

👥 Role-based access (Admin / Editor)

🎥 Video upload → review → approve/reject

⏫ Auto-upload to YouTube after approval

✉ Invite editors with role assignment

🧾 Zod validation + centralized error handling

🗂 Clean project structure & readable code

🎨 Minimal Tailwind UI (simple, fast, modern)

♻ Persistent login & consistent API routes

Everything is written to stay simple, readable, and production-safe — without breaking existing logic.
